О чём этот документ

LOVII — платформа для малого бизнеса, которая помогает удерживать клиентов. Мы строим программу лояльности, каталог местных скидок, инструменты для бизнеса и API для банков.

Что мы делаем: привлекаем инвестиции в обмен на долю в компании LOVII. Оценка выводится из юнит-экономики платформы (см. раздел 6). LOVII развивается внутри ООО «Аксиома» (20 лет на рынке IT, выручка 166 млн ₽).

1. Проблема

В России больше 6 миллионов субъектов малого бизнеса. Большинство не могут позволить себе digital-инструменты для работы с клиентами:

  • CRM, программы лояльности, аналитика стоят от 30 000 ₽/мес — слишком дорого для кафе или салона.
  • Все инструменты разрознены — для каждого нужно отдельное приложение или подписка.
  • Малому бизнесу сложно привлекать клиентов за пределами своей улицы.

2. Что мы делаем

LOVII — это четыре модуля в одной платформе:

  • LOVII Pay — приём платежей по QR-коду, кешбэк баллами. Нагрузка на точку — 10% (из неё 3,5% банк, 6,5% — LOVII-группа).
  • LOVII Club — программа лояльности. Баллы начисляются по инициативе точки через конструктор, тратятся у любых партнёров.
  • LOVII Market — каталог локальных предложений. Покупатель видит, какие скидки есть рядом.
  • LOVII Pro — панель для бизнеса: аналитика, CRM, управление акциями. Стоимость — 2 990 ₽/мес.

Как работают баллы

Баллы LOVII — валюта внутри экосистемы (1 балл = 1 ₽). Они начисляются по инициативе торговой точки через конструктор лояльности, а не автоматически. Баллы не сгорают и выводятся клиентом через СБП. Это исключает мошенничество: каждый рубль кэшбэка привязан к конкретному чеку.

Технологии

Платформа собрана из независимых модулей — поломка одного не ломает всё. Данные каждого города хранятся отдельно. Целевая доступность — 99,5%. После сбоя восстанавливаем работу за 4 часа.

3.2. Распределение дохода с точки (40/40/20)

Весь доход с точки (комиссия + абонплата + комиссия за кэшбэк) делится между участниками:

  • 40% — Компания LOVII + инвестор (доля в компании)
  • 40% — Представители (цифровые агенты сети)
  • 20% — Амбассадоры
