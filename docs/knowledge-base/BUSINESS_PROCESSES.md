## 1. Подключение торговой точки

Цепочка распространения: **Компания → Амбассадор → Представитель → Точка**.
Точка подключается за ~5 минут через QR-код, без сложных договоров.

```mermaid
flowchart TD
    A[Компания LOVII] -->|выдаёт код| B[Амбассадор]
    B -->|выдаёт код| C[Представитель]
    C -->|работает на локации| D[Торговая точка / Партнёр]

    D -->|1. Сканирует QR| E[Регистрация 5 мин]
    E -->|2. CSV / Excel / Web| F[Загрузка товаров]
    F -->|3. Подписание оферты| G[ККТ + онлайн-касса]
    G -->|4. Сплит-маршрутизация| H[Точка в сети]

    H --> I[Готова принимать заказы]
    I -->|доход точки| J[Платит 10% нагрузки + 2 990 ₽/мес PRO]

    style A fill:#f64a8a,color:#fff
    style B fill:#0ABAB5,color:#fff
    style C fill:#D4A854,color:#fff
    style D fill:#F5E6CC
```

**Ключевые факты:**
- Онбординг: **5 минут** (QR для самозанятых, Excel/Web для ИП/ООО)
- Регистрация по публичной оферте (ФЗ-437 ГК РФ)
- Порог 0% комиссии: оборот до **30 000 ₽/мес**

## 2. Покупка клиента

Клиент выбирает товар, оплачивает — банк сплитует платёж: точка получает 90%,
LOVII 6,5%, банк 3,5%.

```mermaid
sequenceDiagram
    participant К as Клиент
    participant А as Приложение LOVII
    participant Б as Банк-эквайер
    participant Т as Торговая точка
    participant Л as LOVII (Компания)

    К->>А: Выбирает товар, в корзину
    А->>К: Итого к оплате (1 000 ₽)
    К->>Б: Оплата картой / СБП
    Б->>Т: Сплит 90% = 900 ₽
    Б->>Л: Сплит 6,5% = 65 ₽
    Б->>Б: Комиссия 3,5% = 35 ₽
    Л->>Л: Распределение 40/40/20 (Компания/Пред/Амбассадор)
    Т->>К: Кассовый чек (ФЗ-54)
    А->>К: Баллы начислены (если точка дала кэшбэк)
```

**Распределение комиссии LOVII (65 ₽):**

| Получатель | Доля | Сумма |
|---|---|---|
| Компания (LOVII) | 40% | 26 ₽ |
| Представитель | 40% | 26 ₽ |
| Амбассадор | 20% | 13 ₽ |

## 3. Кэшбэк и лояльность

Баллы начисляются **только если точка дала кэшбэк** через конструктор лояльности.
Комиссия платформы **25%** от суммы кэшбэка — платит точка сверху.

```mermaid
flowchart LR
    A[Конструктор лояльности точки] -->|настраивает правила| B[Акция в приложении]
    B -->|уведомление жителям локации| C[Клиент видит акцию]
    C -->|покупка с самовывозом 4 000 ₽| D[Начисление кэшбэка 15% = 600 ₽]
    D -->|баллы 1:1 на номинальный счёт| E[Клиент: +600 баллов]
    D -->|комиссия 25% = 150 ₽, платит точка| F[LOVII: 40/40/20]
    E -->|вывод в рубли| G[СБП]

    style A fill:#f64a8a,color:#fff
    style D fill:#D4A854,color:#fff
    style G fill:#0ABAB5,color:#fff
```

**Пример (пиццерия, пятница):**
- Базовый кэшбэк 5% = 200 ₽ (популярные пиццы)
- +10% за самовывоз (чек > 3 500 ₽) = 400 ₽
- Итого 15% = **600 ₽** → баллы клиенту
- Комиссия LOVII 25% от 600 = **150 ₽** (платит точка): Компания 60 / Представитель 60 / Амбассадор 30
- Подарок (пицца за 3 500 ₽) — расход точки, комиссии нет

> **Важно:** баллы НЕ копятся с каждой покупки автоматически. Только по инициативе
> точки через конструктор. 1 балл = 1 ₽, не сгорают, вывод через СБП.

## 4. Доходы и рост сети

```mermaid
pie title Распределение комиссии LOVII (65 ₽ с чека 1 000 ₽)

    "Представитель 40%" : 40

```

### 4.2. Рост статуса представителя

```mermaid
flowchart TD
    A[Цифровой Представитель<br/>до 30 точек] -->|30+ точек| B[Цифровой Мэр<br/>40% + бейдж]
    B -->|3+ города × 30+ точек<br/>выручка сети ≥ 15 млн ₽/мес| C[Цифровой Губернатор<br/>40% + все привилегии]

    style A fill:#F5E6CC
    style B fill:#D4A854,color:#fff
    style C fill:#f64a8a,color:#fff
```

> Цифровые роли — только внутри Лови, без привилегий в реальном мире. Значимы и
> поощряются компанией (заслуги, бейджи, выплаты).

### 4.3. Масштабирование (MVP → Федерация)

```mermaid
flowchart LR
    S1[Ступень 1: MVP<br/>10-20 поставщиков<br/>1 локация] -->|СМУ > 5 млн ₽/мес<br/>> 50 поставщиков<br/>Retention > 40%| S2[Ступень 2: Обмен баллами<br/>между локациями]
    S2 -->|сотни автономных<br/>экономик по РФ| S3[Ступень 3: Федеральная сеть]

    style S1 fill:#F5E6CC
    style S2 fill:#0ABAB5,color:#fff
    style S3 fill:#f64a8a,color:#fff
```

**Целевые показатели:**

| Этап | Метрика | Значение |
|---|---|---|
| MVP (6 мес) | GMV | > 25 млн ₽ |
| MVP (6 мес) | Точки | > 30 |
| Порог масштабирования | GMV / поставщики / Retention | > 5 млн ₽/мес / > 50 / > 40% |
| Зрелая локация (18 мес) | Точки | > 200 |
