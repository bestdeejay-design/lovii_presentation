# LOVII — База знаний (Knowledge Base)

> **Этап:** формирование единого источника истины по параметрам и финансовому контуру
> проекта LOVII. Снимок на 2026-07-17. Дальше от этой базы строится маршрут развития
> документации (продвинутый вариант с БД и авто-обновлением документов).

## Структура

| Файл | Назначение |
|---|---|
| [`PARAMS.md`](PARAMS.md) | Единый источник истины. Все ключевые параметры проекта (комиссии, тарифы, сплиты, роли, палитра, контакты, метрики). Править значения ТОЛЬКО здесь. |

## Ключевые решения владельца (кратко)

- **Комиссия:** полная нагрузка на точку **10%** (из них ~6,5% LOVII + ~3,5% банк). Стартуем с 10%, льготы 4–7% опускаем позже для лидеров.
- **Сплит дохода (базовый):** Компания **40%** / Представитель **40%** / Амбассадор **20%**.
- **Кэшбэк:** начисляется только если точка дала его через конструктор лояльности. Комиссия платформы **25%** от суммы кэшбэка (платит точка сверху).
- **Роли:** цифровые (Представитель → Мэр → Губернатор) — только внутри Лови, без реальных привилегий.
- **Палитра:** белый фон + французский розовый `#f64a8a` (проект `lovii.mobiap.com`).
