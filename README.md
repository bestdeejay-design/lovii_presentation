# LOVII — презентационный сайт и документация

Цифровая инфраструктура для микробизнеса: программа лояльности, приём платежей,
маркетплейс локальных предложений и SaaS-инструменты для бизнеса. Продукт развивает
**ООО «Аксиома»** (материнская IT-компания, 20 лет на рынке, выручка 166 млн ₽).

> **Модель привлечения — доля в бизнесе (equity), не выпуск ЦФА.** Историческая
> модель цифровых финансовых активов упразднена (решение владельца, 2026-07-17).

## Канон проекта (кратко)

Полная версия — [`docs/knowledge-base/CANON.md`](docs/knowledge-base/CANON.md).

- **Нагрузка на точку:** 10% (6,5% LOVII + 3,5% банк).
- **Распределение всего дохода с точки:** 40% Компания+инвестор / 40% Представители / 20% Амбассадор.
- **Тарифы:** А — 6,5% комиссия без абонплаты (60% точек); Б PRO — 4,0% комиссия + 2 990 ₽/мес вперёд (40% точек).
- **База на точку:** 4 чека × 1 200 ₽ × 30 = 144 000 ₽/мес оборот. Доход LOVII-группы с точки ≈ 7 460 ₽/мес.
- **Оценка (P/E 10×):** 500 точек ≈ 107 млн ₽, 1000 ≈ 251 млн ₽, 3000 ≈ 859 млн ₽, 5000 ≈ 1,52 млрд ₽.
- **Без жёстких предложений по раунду и доле** — обсуждается индивидуально.

## Локальный запуск

Статический сайт. Открыть `index.html` напрямую или через любой локальный сервер,
например:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Правила работы с репозиторием

- Правки вносятся локально в клон, проверяются, затем один пуш в `main`.
- Числа и факты правятся в `docs/knowledge-base/PARAMS.md`, затем синхронизируются
  с сайтом и документами.
- Язык проекта — русский.
